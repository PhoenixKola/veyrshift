# Roadmap addendum — first complete release scope

**Date:** 2026-11-06  
**Decision owner:** Project owner direction captured in the B05 completion prompt.

The first complete-release target is **two fully polished heroes, each with three complete forms: six complete transformations total**. “Complete” means every form meets the project's transformation contract: unique silhouette, changed attack chain/mechanics, two modified active moves, mobility/defense variation, finisher, and high-quality animation/VFX/audio in both ordinary encounters and boss fights.

The earlier MVP ambition line in the README referred to four forms. This addendum supersedes that release-target line without editing the historical authoritative V2 vision. The V2 roadmap remains verbatim and unchanged; future planning documents must cite this dated addendum when using the revised release target.

## Current implementation boundary

Kairo is the only playable hero. Ember Drive and Glass Current have prototype combat records and candidate art/presentation work. They do **not** meet the complete-form contract and are not counted among six complete forms. The other hero, the other four release forms, boss-room validation and release-quality approval remain future work. The typed six-hero/42-form catalog is design metadata, not implemented content.
